# Números Reales — Presentación Interactiva

Presentación de diapositivas sobre el sistema de los **Números Reales (ℝ)** con un menú flotante interactivo estilo HUD/terminal.

## 🚀 Demo en vivo

> Despliega en **GitHub Pages** (ver sección de configuración abajo) y abre `index.html`.

---

## 📂 Estructura del proyecto

```
numeros-reales-presentacion/
├── index.html   ← Presentación completa + menú interactivo
├── styles.css   ← Tema HUD oscuro (modo terminal matemático)
└── README.md
```

---

## 🎛️ Menú interactivo — Funciones

| Opción | Tecla | Descripción |
|--------|-------|-------------|
| **Pantalla completa** | `F` | Activa / desactiva modo fullscreen nativo |
| **Ir a diapositiva…** | `G` | Modal para saltar directamente a cualquier slide |
| **Auto-reproducir** | `P` | Slideshow automático con barra de progreso animada |
| **Velocidad** | — | Cicla entre 3 s / 5 s / 8 s / 12 s por diapositiva |
| **Primera diapositiva** | `Home` | Salta al slide 1 |
| **Última diapositiva** | `End` | Salta al slide final |
| **Descargar HTML** | — | Descarga el archivo actual como `.html` |
| **Imprimir / PDF** | `Ctrl+P` | Abre el diálogo de impresión del navegador |

> **Abrir menú:** clic en el botón `☰` (esquina superior derecha) o tecla `M`.

## ⌨️ Atajos de teclado completos

| Tecla | Acción |
|-------|--------|
| `→` / `↓` / `Espacio` | Siguiente diapositiva |
| `←` / `↑` | Diapositiva anterior |
| `Home` | Primera diapositiva |
| `End` | Última diapositiva |
| `F` | Pantalla completa |
| `M` | Abrir / cerrar menú |
| `P` | Auto-play (slideshow) |
| `G` | Ir a diapositiva… |
| `Esc` | Cerrar menú / modal |

## 📋 Contenido — Diapositivas

1. **Portada** — Números Reales, cadena ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ
2. **Clasificación** — Árbol jerárquico del sistema ℝ
3. **Tabla comparativa** — Conjuntos numéricos + diagrama de Venn
4. **Recta numérica real** — Irracionales, racionales y propiedades
5. **Propiedades de ℝ** — Campo ordenado completo
6. **ℚ vs 𝕀** — Racionales vs Irracionales: comparación detallada
7. **Valor absoluto** — Definición, gráfica f(x) = |x|, propiedades
8. **Intervalos en ℝ** — Tipos, notación y representación gráfica
9. **Potencias y radicales** — Leyes de exponentes, f(x) = x² vs √x
10. **Mapa conceptual** — Resumen visual de todo el sistema ℝ

## 🌐 Publicar en GitHub Pages

1. Sube el repositorio a GitHub
2. Ve a **Settings → Pages**
3. En *Source*, selecciona la rama `main` y la carpeta `/ (root)`
4. Haz clic en **Save**
5. En ~2 minutos la URL `https://<usuario>.github.io/<repo>/` estará activa

## 🎨 Tecnologías

- **HTML5 / CSS3 / JavaScript** puro — sin dependencias
- Fuentes: [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) + [Orbitron](https://fonts.google.com/specimen/Orbitron) (Google Fonts)
- Tema HUD oscuro con animaciones CSS (scanline, glow pulse, brackets)
- SVG inline para todos los diagramas y gráficas
- Responsive: escala automáticamente a cualquier tamaño de pantalla
